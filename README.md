# blotter

A positions grid, one chart, and a stream. Nothing on this screen navigates away.

Symbol stays pinned while the other columns scroll. The book filter subsets the rows and the unrealized chart. The stream is a column beside them.

[syedarshad.in](https://syedarshad.in)

[primitives](https://github.com/hybridappdev/primitives)
